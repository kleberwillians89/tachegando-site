# TáChegando — Site independente

Site institucional e fluxo de cadastro de consumidores e vendedores. O projeto é publicado pela Vercel da Mugô. Enquanto a validação de Supabase e confirmação de e-mail não estiver concluída, o cadastro real permanece desativado.

Código originalmente disponibilizado para migração do site `lution-dev/site-tachegando`.
